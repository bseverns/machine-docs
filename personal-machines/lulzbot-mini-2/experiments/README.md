# Experiments log — LulzBot Mini 2

Drop one folder per experiment. Include:
- Slicer profile export (`.curaprofile` or `.3mf`).
- Before/after photos or microscope shots if you're chasing surface quality.
- A short README that states **goal → variables → outcome**.
- Raw observations that would let someone else repeat the trial without you in the room.

If an experiment becomes normal practice, promote the result into [`../machine-card.md`](../machine-card.md), [`../parts-and-spares.md`](../parts-and-spares.md), [`../local-deviations.md`](../local-deviations.md), calibration notes, or the main README instead of letting the good information stay trapped here.

Think lab notebook, but with more riffs and fewer missing settings.
