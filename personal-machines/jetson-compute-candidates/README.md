# Reported Jetson compute candidates

This folder holds Gate D preparation for reported Jetson boards. It is not a canonical inventory, deployment record, or service configuration.

- [`gate-d-audit.md`](gate-d-audit.md) — reported values, per-board physical-audit fields, and the first supervised experiment receipt.
- [`../../templates/compute-device-profile-template.md`](../../templates/compute-device-profile-template.md) — use only after a physically distinct board has evidence suitable for a machine profile.

The current reported fleet is two original Jetson Nanos, probably 4 GB each, and one Jetson Orin Nano developer kit, probably 8 GB. All individual identity and installed-state fields remain unresolved pending physical inspection.
