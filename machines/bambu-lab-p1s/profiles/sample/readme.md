# Sample Validation Files - Bambu Lab P1S

Use `calibration-cube-20mm.stl` as the first local validation print after installation, relocation, service, firmware update, nozzle change, new plate, or new material profile.

Recommended first run:

- Printer: Bambu Lab P1S
- Nozzle: physically verified installed nozzle, normally 0.4 mm until audited otherwise
- Material: dry PLA
- Plate: physically verified and selected in Bambu Studio
- Calibration: full printer calibration first, then print with bed leveling enabled
- Log: add dimensions and notes to `../../logs/sample-run-log.csv`

Do not use this sample as proof that a material is approved. It proves the specific printer/profile/material/plate state used for that run.
