# Preview Notes - Bambu Lab P1S Validation Cube

Before sending the cube:

- Confirm the slicer is set to **Bambu Lab P1S**.
- Confirm nozzle size and build plate match the physical machine.
- Confirm the model imports in millimeters and shows 20 x 20 x 20 mm.
- Use one filament and avoid AMS color changes for baseline validation.
- Keep bed leveling enabled for validation.
- Watch the purge and first layer.

After printing:

- Let the part cool before measuring.
- Measure X, Y, and Z with calipers.
- Inspect first layer, corners, vertical walls, top surface, and seam.
- Record the exact profile and calibration values in the logs.
